# 女性用 お薬・受診手帳

夫用 `../2026-09-19/iphone-web-iphone-api-1-2/dist` をコピーした独立アプリです。公開・GitHubへの送信はしていません。

画面構成、文字サイズ、操作、受診・薬・写真の登録と編集、服用チェック、服用終了、過去の記録、控えの保存と復元、オフライン機能を引き継ぎました。
元のアプリに受診記録全体の削除ボタンはありません。薬は編集時に名前と飲み方を空にして保存すると一覧から外れます。写真は編集画面の「この写真を外す」で除けます。

変更点はピンクの配色と女性の画像・アイコン、女性用のアプリ識別名・保存先・オフライン用キャッシュです。操作のコードは保存先の名前以外、元と同一です。元のGitや公開設定はコピーしていません。

記録はこの端末のブラウザ内に保存します。別の端末には自動で移らず、ブラウザのデータ削除などで失われることがあります。控えを保存してください。

## ローカル確認

このフォルダで `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist` を起動し、`http://127.0.0.1:8766` を開きます。HTMLを直接開くのではなく、確認用サーバーを使用してください。

## 後から画像を差し替える

PillowがあるPythonで `python3 scripts/prepare-icon.py /絶対パス/女性の画像.png` を実行します。
元画像は変更・コピーせず、縦横比を保って512px以内に収め、余白を薄いピンクで埋めます。画面用144px WebPと、ホーム画面用180・192・512px PNGだけを出力します。画像のメタデータは引き継ぎません。キャッシュ番号も更新します。差し替え後は絵や文字の見え方を確認してください。iPhoneに追加済みのアイコンは再追加が必要な場合があります。

対象: `dist/assets/app-icon.webp`、`dist/apple-touch-icon.png`、`dist/assets/icon-192.png`、`dist/assets/icon-512.png`。
画像差し替えで機能や保存記録を変更する必要はありません。公開は別途確認してから行います。

## 女性の画像の組み込み

カレンダーの上に添付画像を小さく配置。元画像はそのまま保管し、画面用は288×427pxのWebP（18,916バイト）。アイコンも同じ画像から作成しPNGは128色に最適化。app.jsは画像追加前と完全に同一で、保存形式・復元処理を変更していません。公開・送信はしていません。
